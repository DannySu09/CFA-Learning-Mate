Setup notes

1. Install the AnkiConnect add-on in Anki.
2. In AnkiConnect's config, set "webCorsOriginList": ["chrome-extension://<your-extension-id>"] — the id is shown at chrome://extensions after loading the extension.
3. When you save a custom API base URL (not api.openai.com), Chrome will ask for permission to reach that host.
